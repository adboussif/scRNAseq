# scRNAseq Analysis

## Description
This project involves the processing and analysis of scRNAseq data from 10X Genomics, using CellRanger for preprocessing and Scanpy for downstream analysis and visualization. The goal is to provide an end-to-end pipeline for single-cell RNA-seq data analysis, from read alignment to cell clustering and marker identification.

## Prerequisites
- **CellRanger**: For read alignment and gene quantification from raw data.
- **Scanpy**: For downstream analysis and visualization.
- **Python 3.8+**
- Python packages: `scanpy`, `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy`

## Installing CellRanger

To install CellRanger, simply execute the installation script:

```bash
bash installation_cellranger.sh
```

This script will:
- Download CellRanger and the necessary reference datasets
- Organize files into structured directories
- Set up the environment automatically

Ensure you have the required permissions and sufficient disk space before running the script.

## Installing Scanpy
Install using pip:
```bash
pip install scanpy
```
Or using conda:
```bash
conda install -c conda-forge scanpy
```

## Steps

### 1. CellRanger Processing
1. Prepare raw data (FASTQ files).
2. Run the CellRanger pipeline (generating a gene count matrix and the associated output files).

### 2. Scanpy Analysis
After obtaining the gene count matrix from CellRanger, proceed with the analysis in Scanpy.

## Results
- A gene expression matrix generated by CellRanger.
- UMAP visualizations showing clustered cells.
- Lists of marker genes identified for each cluster.
