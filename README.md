# scRNAseq Analysis

## Description
This project involves the processing and analysis of scRNAseq data from 10X Genomics, using CellRanger for preprocessing and Scanpy for downstream analysis and visualization. The goal is to provide an end-to-end pipeline for single-cell RNA-seq data analysis, from read alignment to cell clustering and marker identification.

## Prerequisites
- **CellRanger**: For read alignment and gene quantification from raw data.
- **Scanpy**: For downstream analysis and visualization.
- **Python 3.8+**
- Python packages: `scanpy`, `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy`

## Installing CellRanger
Download CellRanger from the [official 10X Genomics site](https://support.10xgenomics.com/single-cell-gene-expression/software/) and follow the installation instructions.

## Installing Scanpy
Install using pip:
```bash
pip install scanpy
```
Or using conda:
```bash
conda install -c conda-forge scanpy
```

## Steps

### 1. CellRanger Processing
1. Prepare raw data (FASTQ files).
2. Run the CellRanger pipeline:
```bash
cellranger count --id=sample_name --transcriptome=/path/to/reference_genome --fastqs=/path/to/fastq_files
```
This command generates a gene count matrix and the associated output files.

### 2. Scanpy Analysis
After obtaining the gene count matrix from CellRanger, proceed with the analysis in Scanpy:

1. **Load data into Scanpy:**
```python
import scanpy as sc

# Load the 10X Genomics matrix
adata = sc.read_10x_mtx('path/to/matrix/', var_names='gene_symbols', cache=True)
```

2. **Quality Control:** Filter out low-quality cells and genes.
```python
sc.pp.filter_cells(adata, min_genes=200)
sc.pp.filter_genes(adata, min_cells=3)
```

3. **Normalization:** Normalize the data.
```python
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
```

4. **Dimensionality Reduction (PCA):**
```python
sc.tl.pca(adata, svd_solver='arpack')
sc.pl.pca_variance_ratio(adata, log=True, n_pcs=50)
```

5. **Clustering:** Compute the neighbors, perform clustering, and visualize using UMAP.
```python
sc.pp.neighbors(adata, n_neighbors=10, n_pcs=40)
sc.tl.leiden(adata)
sc.pl.umap(adata, color=['leiden'])
```

6. **Marker Identification:** Identify marker genes for each cluster.
```python
sc.tl.rank_genes_groups(adata, 'leiden', method='t-test')
sc.pl.rank_genes_groups(adata, n_genes=25, sharey=False)
```

## Results
- A gene expression matrix generated by CellRanger.
- UMAP visualizations showing clustered cells.
- Lists of marker genes identified for each cluster.
