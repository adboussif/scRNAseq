# scRNAseq Analysis

## Description
This project involves the processing and analysis of single-cell RNA sequencing (scRNAseq) data from 10X Genomics. The pipeline uses **Cell Ranger** for preprocessing (read alignment, gene quantification, and feature barcode analysis) and **Scanpy** for downstream analysis and visualization. The goal is to provide an end-to-end workflow for scRNAseq data analysis, from raw data processing to cell clustering, marker gene identification, and visualization.

---

## Prerequisites
### Software and Tools
- **Cell Ranger** : For read alignment, gene quantification, and feature barcode analysis.
- **Scanpy** : For downstream analysis and visualization.
- **Python 3.8+**: Required for running Scanpy and associated Python packages.
- **Jupyter Notebooks**: For interactive analysis and visualization.

### Python Packages
- Required packages: `scanpy`, `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy`
- Install all dependencies using:
  ```bash
  pip install scanpy numpy pandas matplotlib seaborn scipy
  ```

## Data Overview
The dataset used in this project consists of Dissociated Tumor Cells (DTC) from a melanoma study. The data includes:
- **FASTQ files**: Raw sequencing reads.
- **Feature Barcodes**: Additional information for cell surface protein or CRISPR perturbation analysis (if applicable).
- **Reference Genome**: Pre-built reference genome for alignment.

Additional files provided (optional):
- **ProbeSet**: Contains probe information for feature barcode analysis.
- **Telemetry**: Metadata or environmental data (e.g., temperature, pressure) collected during sequencing.
- **Gemcode**: Legacy files from older 10X Genomics kits (not required for this analysis).

## Pipeline Overview

### 1. Cell Ranger Processing
1. **Prepare Raw Data**: Organize FASTQ files and ensure they are named correctly.
2. **Run Cell Ranger**:
   - Align reads to the reference genome.
   - Generate a gene count matrix and feature barcode counts (if applicable).
   - Output files include:
     - `filtered_feature_bc_matrix.h5`: Gene expression matrix.
     - `cloupe.cloupe`: Visualization file for Loupe Browser.
     - `web_summary.html`: Quality control report.

   Example command:
   ```bash
   cellranger 
   ```

### 2. Scanpy Analysis
After obtaining the gene count matrix from Cell Ranger, proceed with the analysis in Scanpy:
1. **Load Data**: Import the gene count matrix into Scanpy.
2. **Preprocessing**:
   - Filter cells and genes based on quality metrics.
   - Normalize and log-transform the data.
3. **Dimensionality Reduction**:
   - Perform PCA and UMAP/t-SNE for visualization.
4. **Clustering**: Identify cell clusters using algorithms like Leiden or Louvain.
5. **Marker Gene Identification**: Find differentially expressed genes for each cluster.
6. **Visualization**: Generate UMAP plots, violin plots, and heatmaps.

## Results
- **Gene Expression Matrix**: Generated by Cell Ranger, containing counts for each gene and cell.
- **UMAP Visualizations**: 2D/3D plots showing cell clusters.
- **Marker Genes**: Lists of genes that are differentially expressed in each cluster.
- **Quality Control Metrics**: Summary statistics and plots for cell and gene filtering.
